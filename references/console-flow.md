# 操作台

## 连接

| 项 | 规则 |
|---|---|
| 形态 | 单文件 `console.html`，无构建、无 npm / pip 依赖 |
| 板块 | 只有 `01 文生图`、`02 画师串批量` |
| 地址 | 界面里没有地址输入框；`file://` 打开直连 `127.0.0.1:8188`，`http://` 打开用同源地址（`8765` 中继） |
| 跨域失败 | 自动落到同源中继；仍失败才显示错误面板，不显示技术原因 |
| 就绪提示 | 顶栏一个圆点 +「已就绪 / 未就绪 / 正在准备」，旁边「重新连接」 |
| 配方与档位 | 只由 `plan.json` 的 `recipe` / `max_side` 决定，页面不显示这两个值 |

## 01 文生图

提示词多行输入 + 实时字数；尺寸四档；种子数值 +「随机」；成图保存位置只读展示 +「选择 / 清除」；按钮「生成一张」，出图中显示遮罩与进度条并锁按钮。输出区：空态提示、等比不裁切预览、底部四格 Seed / Size / Time / 保存状态。

## 02 画师串批量

提示词独立输入，与 01 互不影响；尺寸同 01；画师串来自 `artists.json`，多选 +「全选 / 清空」+「已选 N 个」；一个 seed 覆盖整批，保证只有画风在变；按钮显示「N 张」，未选时禁用。

批量行为：

1. 按条目顺序**串行**提交，同一 seed，一次只跑一张。
2. 右侧按选中数量生成网格，一图一串，标题即画师串名。
3. 每帧三态：待生成 / 出图中 / 完成（附单张耗时）；失败帧标「没出成」，**不中断其余**。
4. 结束汇总：全成「全部出好了」；有失败「有 N 张没出成」并弹错误面板。
5. 插入位置（内部逻辑，界面不展示）：`1girl / 1boy / 2girls / 2boys` 之前 → 否则 `intricate details` 之前 → 否则开头。

## 尺寸四档（随 `max_side` 折算）

| `max_side` | 竖图 | 横图 | 方图 | 试稿 |
|---|---|---|---|---|
| 1536 | 960×1536 | 1536×960 | 1024×1024 | 768×768 |
| 960 | 720×960 | 960×720 | 960×960 | 640×640 |
| 768 | 576×768 | 768×576 | 768×768 | 512×512 |

## 提示词拼装

- 正向：用户输入 + 选中的画师串按上面的锚点插入；生成前必须回显最终提示词，至少一句「我理解成了这样」，允许修改。
- 负向：固定取 `presets.json` 的 `internal.negative`，界面不可改。
- 默认走 `anima-neo-generation` 的「艺术化模式」，「标准化模式」为可选。

## 成图保存位置

| 情形 | 行为 |
|---|---|
| 已指定 | 每张自动写入，文件名 `Anima_<画师串|plain>_<seed 后 8 位>_<时间戳>.png`，画师串去掉 `@` 与非字母数字字符 |
| 未指定 | 不自动落盘；01 显示「保存这张」，02 每帧下方显示「保存」 |
| 浏览器不支持目录写入 |「选择」置灰为「不可用」，提示改用单张保存，不弹技术错误 |
| 写入失败 | 错误面板 +「复制报错信息」；图仍在页面上可另存 |

01 与 02 的保存位置互相独立；清除只清当前板块。

## 错误面板（唯一报错出口）

固定两句：

> **没出成。**
> 请让您的 Agent 检查此问题。

两个按钮：「复制报错信息」复制「时间 / 环节 / 服务 / 信息 / 堆栈」五段纯文本，成功后短暂变「已复制」；「再试一次」重跑上一次动作。原始报错、状态码、接口路径、端口只进剪贴板；不用 `alert`，顶部轻提示只允许「先写一句提示词」「已保存」这类短句。

## 界面禁用词

端口号、`127.0.0.1`、`/prompt`、`/history`、`/view`、CORS、`python_embeded`、命令行、启动参数、模型文件名、LoRA 名、强度、steps、cfg、sampler、scheduler、报错原文、堆栈、HTTP 状态码、节点名、工作流文件名——全部不出现在页面。
